🩸 BloodLink – Smart Emergency Blood Coordination Platform

🔴 Live Demo: "Visit BloodLink" (https://taskeenshaikh709-lang.github.io/BloodLink/)

📌 About the Project

BloodLink is a healthcare technology prototype designed to streamline emergency blood request coordination. It helps connect hospitals, blood banks, and individuals through a centralized platform.

✨ Key Features

- Emergency blood request creation
- Blood bank availability updates
- Request acceptance and rejection workflow
- Request tracking
- Separate dashboards for different user roles
- Verified directory interface
- Demo data for prototype testing

🛠️ Tech Stack

Frontend: React.js, Tailwind CSS, JavaScript

Backend: Python, Flask

Other tools: Git, GitHub, Vite
